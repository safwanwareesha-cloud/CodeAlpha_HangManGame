Hangman Game 🎮

A simple text-based Hangman game built using Python. The player has to guess the hidden word one letter at a time before running out of incorrect guesses.

Features
5 predefined words
Random word selection
Maximum 6 incorrect guesses
Displays correctly guessed letters
Prevents duplicate letter guesses
Simple console-based gameplay
Technologies Used
Python
Random module
Lists
Strings
While loops
If-else statements
How to Run
Make sure Python is installed on your computer.
Download or clone this repository.
Open the project folder in Terminal or PowerShell.
Run:
python main.py

If python doesn't work, try:

py main.py
How to Play
Run the game.
Guess one letter at a time.
Correct guesses reveal the letters in the hidden word.
You can make up to 6 incorrect guesses.
Guess the complete word before reaching the limit to win.
Project

This project was created as part of an internship project to practice basic Python programming concepts and build a simple console-based game.
